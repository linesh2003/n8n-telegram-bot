# NEXUS Telegram Bot Orchestrator

Automated Telegram bot built with n8n using webhook triggers, Switch-based message routing, and error handling nodes.

## Tech
n8n (self-hosted) | Telegram Bot API | Webhooks | Switch Node | Error Handling

## How to Use
1. Import the JSON file into n8n
2. Add your Telegram Bot API token
3. Set up a webhook URL
4. Activate the workflow
